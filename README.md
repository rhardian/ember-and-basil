Ember & Basil is an offline desktop artisan bistro cooking game featuring a Dual-Chef Brigade (Chef Marco & Sous-Chef Sofia with queued BFS routing), 12 combinatorial dishes, live °C sweet-spot searing and 420°C brick-oven baking, 3 lighting biomes, candlelit dining regulars & VIP critic, and 6 kitchen equipment upgrades.

## Run it

```sh
node serve.ts
# Then open http://127.0.0.1:8080 in Chrome (or package with MAKEFUN_OUTPUT_DIR=out node main.ts)
```
