Ember & Basil is a sunlit artisan bistro cooking game built with zero external dependencies for desktop browsers, combining multi-station kitchen routing, sweet-spot skillet searing, stone-oven baking, combinatorial recipes, and responsive keyboard and mouse controls.

## Run it

```sh
node serve.ts
# Then open http://127.0.0.1:8080 in Chrome (or package with MAKEFUN_OUTPUT_DIR=out node main.ts)
```
